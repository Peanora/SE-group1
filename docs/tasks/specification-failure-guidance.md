# 规格失败说明与免费重新校验
基准563af4e，独立分支codex/specification-failure-guidance。
事实：用户补充回答后模型输出引用包含平台自己添加的“答复：”标签，被引用白名单拒绝；异常原因又被统一为invalid_model_response，预算用尽后仍展示重试。
目标：仅规范化可逐字定位且末尾答案仍属于原文/用户回答的引用包装；固定错误原因与恢复提示，不透传模型异常；可信保存响应可由用户显式免费重新校验，旧失败/用量不改写。预算耗尽不新增请求。实际原回执只用于本地离线复核，不提交。
范围：解析、私有回执读取、规格失败DTO/动作、页面错误和恢复、回归与契约。无付费调用，不自动修改原用户运行。

实现与数据流：normalizeSourceQuote只移除合成输入真实存在的包装，再核对原文/回答白名单；私有回执离线复核与人工修订复用同规则。规格失败原因仅使用固定枚举和1-80需求索引，不透传原始异常。GET诊断返回specificationFailure，不写用户记录。revalidate_spec只读服务器自有hash绑定响应，核对最后尝试、输入、项目/运行归属及最终异步窗口，先形成新规格再持久化；失败回滚。新specificationRevalidations独立记录恢复依据，原模型失败与用量不改写。调用预算耗尽retry入口409，前端禁用；恢复后仍需两次确认。
