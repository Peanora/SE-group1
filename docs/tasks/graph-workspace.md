# 流程图工作台

基线为 `4536436`。验收目标是在首屏按真实项目和运行展示可操作的流程图，并从节点走到原有规格、计划、联合验收和交付入口。

## 布局与数据

- 用横向顶栏及项目列表取代原左栏，把当前待办、运行操作和历史放到流程图右侧。390px 下操作区排在画布下方。导入说明保留在空项目操作区。
- 九步画布默认展开。节点状态取自 `deliverySteps()`，根据当前项目、所选运行、验收清单及开发证据更新。点击仍通过 `openDeliveryStage()` 定位现有操作和证据。图例和箭头用于阅读，后端继续决定审批、派发、验收与源码下载。
- 阶段证据图、开发模块图和逐任务执行图沿用已有依赖及节点事件。开发模块画布保留同层换位、缩放、选中、连线编辑和保存后重新确认。相邻依赖改用曲线，跨层依赖仍走既有通道。
- 总体排版参考固定版 Factory 的顶栏、点阵画布与右侧检查区，Taskflow 使用自己的项目和证据界面。项目标题旁的 Factory 入口复用现有 v1.0.5 原生执行、Git 工作区和规格交接。 [上游工作台](https://github.com/OmegaMc1331/agentic-software-factory/blob/f90f7be9406555980d733d81e57ad86f097f57ff/docs/assets/dashboard-network.png) · [本机入口](../FACTORY_WORKBENCH.md)
