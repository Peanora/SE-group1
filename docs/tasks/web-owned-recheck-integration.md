# 网页固定代码重新检查集成

日期：2026年11月14日。基准：`d5ffc75`（代码`2365067`），工作树`teamwork-web-owned-recheck-integration`。

真实网页首轮候选已通过自检、独立HTTP/SQLite及Edge，但Review意见缺少evidence，整轮正确失败。目标是在网页保留原代码和失败历史，发起0编码的新检查尝试；新测试和有效Review全部通过后才可预览、下载并复现。有效阻塞问题仍须修复后新版本复验。

分工：核心来源/输出校验、服务及执行面板在独立工作树实现；此集成树唯一维护server动作白名单、HTTP接线回归、集成检查及文档。客户端只提交动作，不得传来源路径、报告、版本绑定或预算。来源仅由服务持有的当前双确认及私有原执行记录决定，不从HTTP获得可信归属。

验收：固定各组件提交并经独立审查后集成；校验合法动作、越权/路径和过期版本拒绝；新增尝试编码0、Review按实际计量、旧记录原样；独立快照无伪造Git元数据，来源真实提交及回执重新核对；新门禁失败、未知停止或取消不得发布成功。实际浏览器完成成本确认、重新检查、预览及下载；成功包在新目录运行固定外部验收。每次真实模型失败保留，不以重试次数替代质量。

本记录为实施目标，未运行的验收不记为完成；尚不支持任意上传业务、递归来源、通用Worker恢复或多任务集成。
